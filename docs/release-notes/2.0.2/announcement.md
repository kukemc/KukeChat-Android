2.0.2 更新内容包括：
- 新增接龙红包：领取时会自动发出发红包的人设定的一句话
- 新增专属红包：在群里指定一个人，只有他能领
- 聊天里有没领的红包时，右上角会提示，点一下就跳过去
- 发消息、发图片会马上显示在聊天里，发送失败可以点击重发
- 可以一次选多张图片，发送前能先预览确认
- 表情回应多了很多表情，可以滑动选择，长按还能看到都是谁回应的
- 群文件支持文件夹了（Pro+ 和 MAX 群）
- 群文件可以搜索了
- CCW 作品链接和 B 站视频链接会显示成卡片，点 B 站卡片能直接打开 B 站
- 跳转到某条消息时会停在屏幕中间并高亮，跳到很久以前的消息也能直接定位过去
- 滑动回复会自动弹出键盘
- 动图表情能正常播放了，小表情也不会再显示得一点点大
- 气泡皮肤和头像框的花纹、装饰和动效都能正常显示了
